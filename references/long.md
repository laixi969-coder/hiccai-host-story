# 长篇

用户要长篇、万字、一万字时用这一档。短篇骨架不要拿来写长篇。

全篇八千到一万二千字。分成四到六程。每一程一千五百到两千五百字。

全篇只有一种世界观、一条规律或一套秩序、一盘醋、一种快感。不在中途换世界，也不另加第二条规律。

每一程自己完整：有一个能跟着走完的人，有他这一程要做成的一件具体的事，规律或秩序落到他身上，他因此做事，有转折，有结尾的动作。下一程使用上一程留下的后果，不把世界重置。

新闻日的九步和一间房的五步不要在每一程里重演。主播最多在全篇出现一次。体面的办法也只推出一次，放在后半，而且正好是这些人私下想要的。

当下被改写：每一程换一个人，或回到前面的人，但都活在同一条规律里。最后一程用第一程的那个物件做结尾。认账的问句只在最后一程出现一次。结尾不把题答完。

秩序即世界：秩序只讲清一次。前面的程先给后果。后面的程让人用这套秩序去够那件不肯承认的事，每次代价落到一个具体的人身上。最后一程扣死。第一程那个看不懂的后果，就是这件事。

单篇不硬加彩蛋。写完用 world.md 的原创检验看全篇。某一程单独拿出来像另一部电影的某一段，就重写那一程。
